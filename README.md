# parkquasar.github.io

Personal page of Junsung Park. Plain HTML and CSS, no build step.

- `index.html`: all content. Each paper is one `<article class="pub">` block, newest first; first-author papers also have the class `first`.
- `assets/style.css`: layout and colours.
- `assets/img/`: profile photo and paper figures (WebP).
- `Junsung_Park_CV.pdf`: replace this file when the CV changes.
- `assets/fonts/`: Inter and Source Serif 4 (SIL Open Font License, see the licence files there).
